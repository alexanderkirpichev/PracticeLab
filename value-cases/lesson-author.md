# Value Cases: Автор курса

## Value Case: Автор курса — создать курс [MVP]

### Обстоятельства
- Курс ещё не создан.
- Автор определил тему нового курса.

### Возможные результаты
- Созданный курс
  - Автор курса

### Что понадобится
- Платформа PracticeLab — Увидеть шаблон курса
- Веб-сервис — Увидеть созданный курс

## Value Case: Автор курса — разработать курс

### Обстоятельства
- Курс находится в статусе «Разрабатываемый».
- Материалы курса ещё не готовы.

### Возможные результаты
- Разработанный курс
  - Автор курса

### Что понадобится
- Платформа PracticeLab — Увидеть структуру курса
- Веб-сервис — Получить готовые иллюстрации для курса

## Value Case: Автор курса — назначить проверяющего на курс [MVP]

### Обстоятельства
- Курс разработан.
- У курса ещё нет назначенного проверяющего.

### Возможные результаты
- Назначенный на курс проверяющий
  - Автор курса

### Что понадобится
- Платформа PracticeLab — Увидеть список проверяющих
- Веб-сервис — Увидеть подтверждение назначения

## Value Case: Автор курса — опубликовать курс [MVP]

### Обстоятельства
- Курс разработан.
- Курс ещё не опубликован.

### Возможные результаты
- Активный курс
  - Автор курса

### Что понадобится
- Платформа PracticeLab — Увидеть статус курса
- Веб-сервис — Увидеть опубликованный курс

## Value Case: Автор курса — провести занятие

### Обстоятельства
- Курс в расписании.
- Занятие согласовано с учеником.

### Возможные результаты
- Проведённое занятие
  - Автор курса

### Что понадобится
- Платформа PracticeLab — Увидеть расписание занятия
- Веб-сервис — Увидеть онлайн-занятие
