# Value Cases: Проверяющий

## Value Case: Проверяющий — проверить работу ученика [MVP]

### Обстоятельства
- Работа ученика находится в статусе «На проверке».
- Проверяющий видит выполненную работу.

### Возможные результаты
- Принятая работа
  - Проверяющий
- Работа, возвращённая на доработку
  - Проверяющий

### Что понадобится
- Платформа PracticeLab — Увидеть работу ученика
- Веб-сервис — Получить работу на проверку

## Value Case: Проверяющий — сообщить результат проверки ученику

### Обстоятельства
- Работа проверена.
- Результат проверки ещё не отправлен.

### Возможные результаты
- Отправленный результат проверки
  - Проверяющий

### Что понадобится
- Платформа PracticeLab — Увидеть результат проверки
- Веб-сервис — Увидеть отправленное уведомление о результате
