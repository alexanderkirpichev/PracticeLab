# Value Cases: Ученик

## Value Case: Ученик — записаться на курс [MVP]

### Обстоятельства
- Ученик выбрал активный курс.
- Ученик ещё не записан на курс.

### Возможные результаты
- Записанный на курс ученик
  - Ученик

### Что понадобится
- Платформа PracticeLab — Увидеть список активных курсов
- Веб-сервис — Увидеть подтверждение записи

## Value Case: Ученик — пройти урок [MVP]

### Обстоятельства
- Ученик записан на курс.
- Урок доступен для прохождения.

### Возможные результаты
- Пройденный урок
  - Ученик

### Что понадобится
- Платформа PracticeLab — Увидеть шаги урока
- Веб-сервис — Увидеть материалы урока

## Value Case: Ученик — отправить работу на проверку [MVP]

### Обстоятельства

### Возможные результаты

### Что понадобится

- Веб-сервис — Увидеть работу, отправленную на проверку

## Value Case: Ученик — получить обратную связь по выполненной работе

### Обстоятельства
- Ученик подготовил работу по уроку с ревью.
- Работа отправлена на проверку, проверяющий недоступен сразу.

### Возможные результаты
- Полученные замечания по работе
  - Ученик
- Доработанная работа, отправленная повторно
  - Ученик

### Что понадобится
- Платформа PracticeLab — Увидеть статус своей работы
- Веб-сервис — Получить замечания по работе

## Value Case: Ученик — проверить выполнение практического задания

### Обстоятельства

  - Ученик

- Веб-сервис — Увидеть результат проверки кода

## Value Case: Ученик — не пропустить срок сдачи работы

### Обстоятельства

### Возможные результаты
- Сданная в срок работа
  - Ученик
- Работа без отставания
  - Ученик

### Что понадобится
- Платформа PracticeLab — Увидеть срок сдачи работы
- Веб-сервис — Получить напоминание о сроке сдачи
